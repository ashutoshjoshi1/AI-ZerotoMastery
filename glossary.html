Glossary

Plain-language definitions of the terms used in this course. The lesson number after each definition links to where the idea is explained properly. Press / to search for any term.

A#

Activation function
The non-linear function applied after a layer's weighted sum (ReLU, GELU, sigmoid). Without it, stacked layers collapse into one linear layer. 05
Adam / AdamW
The default optimiser for deep learning. Keeps running averages of gradients and squared gradients to give each parameter its own step size; AdamW adds decoupled weight decay. 05
Agent
A model using tools in a loop, deciding for itself what to do next until a task is done. 14
ANN (approximate nearest neighbour)
Index structures such as HNSW and IVF that find most of the nearest vectors far faster than exact search. 12
Attention
The mechanism by which each token computes a weighted mix of other tokens' information, using query-key similarity: softmax(QKᵀ/√d)V. 08
Autograd
Automatic differentiation: a framework records operations and computes gradients by applying the chain rule backwards. 06

B#

Backpropagation
The algorithm that computes the gradient of the loss with respect to every weight by applying the chain rule from the output back to the input. 05
Base model
A model after pretraining only. It continues text rather than following instructions. 09
Batch (mini-batch)
A group of examples processed together in one training step. 05
Bias-variance trade-off
Simple models err through wrong assumptions (bias, underfitting); flexible models err through sensitivity to the training sample (variance, overfitting). 03
BM25
A classic keyword-ranking function that rewards rare query terms, with diminishing returns for repeats and a document-length correction. 13
Bootstrap
Resampling your data with replacement many times to estimate the uncertainty of a metric. 15
BPE (byte-pair encoding)
A tokenizer training method that repeatedly merges the most frequent adjacent pair of tokens into a new token. 09
Broadcasting
NumPy and PyTorch rules for combining arrays of different shapes by virtually stretching size-1 dimensions. 01

C#

Chain-of-thought
Prompting or training a model to produce intermediate reasoning before its final answer. 11
Chat template
The special-token format a chat model was trained with to mark system, user and assistant turns. Training and serving must use the same one. 16
Chunking
Splitting documents into retrievable pieces for RAG. 13
CLIP
A model that embeds images and text into a shared space, enabling zero-shot image classification and cross-modal search. 19
Context window
The maximum number of tokens (input plus output) a model can attend to in one request. 09
Contrastive learning
Training that pulls matching pairs together and pushes non-matching pairs apart in an embedding space. 12
Cosine similarity
The cosine of the angle between two vectors: 1 for same direction, 0 for perpendicular. The standard similarity for embeddings. 02
Cross-encoder
A model that reads a query and a document together to score relevance. Accurate but slow; used for reranking. 13
Cross-entropy
The loss −log p(correct answer). The training objective of classifiers and LLMs. 02
Cross-validation
Training and validating k times on different splits of the data and averaging, for a more reliable estimate. 03

D#

Data leakage
Information in training or evaluation data that would not be available at prediction time, producing falsely good scores. 03
Decoder-only
A transformer with causal attention trained to predict the next token. The architecture of GPT-style LLMs. 08
Diffusion model
A generative model that learns to remove noise step by step, generating images (or audio, video) from pure noise. 19
Distillation
Training a small student model to imitate a larger teacher. 16
DPO (direct preference optimisation)
Training directly on preference pairs (chosen versus rejected) without a separate reward model or RL loop. 09, 16
Dropout
Randomly zeroing activations during training to reduce overfitting. 05

E#

Embedding
A learned vector representation whose geometry reflects meaning. 07, 12
Epoch
One full pass over the training data. 05
Evaluation set (golden dataset)
A curated set of inputs with expected outcomes or grading criteria used to measure a system. 15

F#

F1 score
The harmonic mean of precision and recall. 03
Few-shot prompting
Including worked examples of the task in the prompt. 11
Fine-tuning
Continuing to train a pretrained model on task-specific data. 16
FlashAttention
An exact attention algorithm that avoids materialising the full attention matrix in slow GPU memory, making long contexts faster. 08
FLOPs
Floating-point operations; training a transformer costs about 6 × parameters × tokens. 09

G#

Gradient
The vector of partial derivatives of the loss with respect to each parameter; points uphill. 02
Gradient boosting
An ensemble of shallow trees added one at a time, each correcting the errors of the ones before. Often the best model for tabular data. 04
Gradient descent
Repeatedly stepping parameters against the gradient to reduce the loss. 02
Grouped-query attention (GQA)
Many query heads sharing fewer key-value heads, shrinking the KV cache. 08
Guardrails
Controls around a model: input and output checks, permissions, approvals and limits. 18

H#

Hallucination
Fluent, confident output that is false or unsupported. 09
HNSW
A graph-based approximate nearest-neighbour index, the default in many vector databases. 12
Hybrid search
Combining keyword and embedding retrieval, typically with reciprocal rank fusion. 13
Hyperparameter
A setting chosen rather than learned, such as learning rate, tree depth or LoRA rank. 03

I#

Inference
Using a trained model to make predictions or generate output. 17
Isolation Forest
An anomaly detector that isolates points with random splits; anomalies isolate quickly. 04

K#

KL divergence
A measure of how one probability distribution differs from another; used in distillation and RLHF. 02
KV cache
Stored keys and values of previous tokens that make generation efficient at the cost of memory. 08

L#

Layer normalisation
Rescaling each token's features to zero mean and unit variance; stabilises transformer training. 05
Learning rate
The step size in gradient descent; the most important training hyperparameter. 02
LLM-as-judge
Using a model to grade outputs against a rubric; must be calibrated against human judgement. 15
Logits
Raw, unnormalised model scores before softmax. 02
LoRA
Low-rank adaptation: fine-tuning by learning a small low-rank update beside frozen weights. 16
Loss function
The number training minimises, measuring how wrong the model is. 02

M#

MCP (Model Context Protocol)
An open standard for exposing tools, resources and prompts to AI applications. 14
Mixed precision
Training or inference mostly in 16-bit floating point for speed and memory, keeping sensitive parts in 32-bit. 06
Mixture of experts (MoE)
Layers with many expert sub-networks and a router that sends each token to a few of them. 09
Multi-head attention
Several attention operations in parallel on smaller subspaces, then combined. 08

O#

Overfitting
Learning the noise in the training data; low training error, high validation error. 03

P#

PagedAttention
vLLM's technique of storing the KV cache in pages to avoid memory fragmentation. 17
PCA
Projecting data onto its directions of greatest variance, for compression or visualisation. 04
Positional encoding
Information about token order added to a transformer, which is otherwise order-blind (learned, sinusoidal or RoPE). 08
Precision and recall
Precision: of the positives predicted, the fraction that were right. Recall: of the real positives, the fraction found. 03
Prefill
Processing the prompt before generating the first token; also, starting the assistant's reply with given text. 11, 17
Pretraining
Training a model on a huge unlabelled corpus with next-token prediction. 09
Prompt caching
Reusing the processed form of a repeated prompt prefix at reduced cost and latency. 10
Prompt injection
Text that tries to override a system's instructions, directly from a user or indirectly via content the model reads. 18

Q#

QLoRA
LoRA on top of a base model stored in 4-bit precision. 16
Quantisation
Storing weights (or activations, or the KV cache) in fewer bits to save memory and speed up inference. 17

R#

RAG (retrieval-augmented generation)
Retrieving relevant documents at question time and asking the model to answer from them. 13
Reasoning model
A model trained to produce extended reasoning before answering, improving with more test-time compute. 09
Reciprocal rank fusion (RRF)
Merging rankings by summing 1/(k + rank) across retrievers. 13
Regularisation
Techniques that discourage overly complex models, such as weight penalties, dropout and early stopping. 03
Reranker
A model, usually a cross-encoder, that reorders retrieved candidates by relevance. 13
Residual connection
Adding a layer's input to its output (x + f(x)), letting gradients flow through deep networks. 05
RLHF
Reinforcement learning from human feedback: optimising a model against a reward model trained on human preferences. 09
RoPE
Rotary position embeddings, which encode relative position by rotating queries and keys. 08

S#

Scaling laws
Empirical power laws relating model loss to parameters, data and compute. 09
Self-supervised learning
Learning from labels derived from the data itself, such as the next word. 03
SFT (supervised fine-tuning)
Fine-tuning on examples of desired inputs and outputs. 09, 16
Softmax
Converts logits to probabilities that sum to 1. 02
Streaming
Sending generated tokens to the client as they are produced. 10
Structured output
Constraining model output to a schema, then validating it. 10
System prompt
Standing instructions and context for a conversation. 10

T#

Temperature
Divides logits before softmax; low values make output more deterministic, high values more random. 09
Tensor
A multi-dimensional array, the core data structure of deep learning frameworks. 06
Test-time compute
Spending more computation at inference (longer reasoning, sampling several answers) to improve accuracy. 09
Token
The unit of text a model reads and writes, typically a word piece of about four characters in English. 09
Tool use (function calling)
A model requesting structured calls to functions your code executes. 14
Top-p (nucleus) sampling
Sampling only from the smallest set of tokens whose probabilities sum to p. 09
Tracing
Recording every step of a request (retrieval, model calls, tools) for debugging and monitoring. 17
Transfer learning
Reusing a model trained on one task as the starting point for another. 06
Transformer
The architecture of stacked attention and MLP blocks with residual connections and normalisation behind modern LLMs. 08
TTFT (time to first token)
Latency until the first output token appears; dominated by prompt length. 17

U–Z#

Underfitting
A model too simple to capture the pattern; high training and validation error. 03
Vector database
A database that stores embeddings with metadata and supports similarity search with filters. 12
Vision transformer (ViT)
A transformer that processes images as sequences of patches. 19
VLM (vision-language model)
A model that accepts images alongside text. 19
Weight decay
An L2-style penalty that shrinks weights during training. 03
Zero-shot
Performing a task with no task-specific examples or training. 19
