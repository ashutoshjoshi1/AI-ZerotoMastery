Glossary

229 terms you will meet in the course, in plain language. The number after each definition is the lesson that teaches it.

ABCDEFGHIKLMNOPQRSTUVWZ

A

A*
Best-first search that expands the state with the lowest cost so far plus heuristic estimate, and returns an optimal path when the heuristic is admissible. 24
Activation function
The non-linear function applied after a layer's weighted sum (ReLU, GELU, sigmoid). Without it, stacked layers collapse into one linear layer. 05
Activation patching
Copying an activation from one run of a model into another run to measure whether that activation causes a difference in the output. 30
Adam / AdamW
The default optimiser for deep learning. Keeps running averages of gradients and squared gradients to give each parameter its own step size; AdamW adds decoupled weight decay. 05
Agent
A model using tools in a loop, deciding for itself what to do next until a task is done. 15
Alpha-beta pruning
A refinement of minimax that skips branches which cannot change the decision, giving the same answer with far less search. 24
Anchor box
A reference box of fixed size and shape at a position on the feature map, which a detector scores and adjusts to fit a nearby object. 27
ANN (approximate nearest neighbour)
Index structures such as HNSW and IVF that find most of the nearest vectors far faster than exact search. 13
ARIMA
A classical forecasting model that differences a series to remove trend, then predicts from its own past values and past forecast errors. 28
Arithmetic intensity
The number of floating-point operations an operation performs per byte it reads or writes from memory. 29
Artificial intelligence (AI)
Any technique that makes machines act intelligently, whether by hand-written rules or by learning. 00
Attention
The mechanism by which each token computes a weighted mix of other tokens' information, using query-key similarity: softmax(QKᵀ/√d)V. 08
Autoencoder
A network that compresses its input to a small code with an encoder and rebuilds it with a decoder, trained to make the rebuild match the input. 26
Autograd
Automatic differentiation: a framework records operations and computes gradients by applying the chain rule backwards. 06

B

Backpropagation
The algorithm that computes the gradient of the loss with respect to every weight by applying the chain rule from the output back to the input. 05
Backtesting (walk-forward validation)
Evaluating a forecaster by repeatedly training on the past and scoring on the period that follows, never on shuffled data. 28
Base model
A model after pretraining only. It continues text rather than following instructions. 09
Batch (mini-batch)
A group of examples processed together in one training step. 05
Batch API
An endpoint that accepts thousands of requests at once and returns the results within hours at a discount. 10
Bayesian network
A directed graph of random variables in which each variable depends only on its parents, giving a compact model of a joint probability distribution. 24
Bellman equation
The recursive rule that a state's value equals the expected immediate reward plus the discounted value of the next state. 25
Best-of-N
Generating N candidate answers and keeping the one a verifier or reward model scores highest. 12
bf16 (bfloat16)
A 16-bit floating-point format with float32's range but only about three significant digits, the standard format for training. 29
Bi-encoder
An embedding model that encodes the query and each document separately, so documents can be indexed once and searched fast. 13
Bias-variance trade-off
Simple models err through wrong assumptions (bias, underfitting); flexible models err through sensitivity to the training sample (variance, overfitting). 03
BM25
A classic keyword-ranking function that rewards rare query terms, with diminishing returns for repeats and a document-length correction. 14
Bootstrap
Resampling your data with replacement many times to estimate the uncertainty of a metric. 17
Bounding box
The smallest axis-aligned rectangle around an object, stored as four numbers such as its corners (x1, y1, x2, y2). 27
BPE (byte-pair encoding)
A tokenizer training method that repeatedly merges the most frequent adjacent pair of tokens into a new token. 09
Broadcasting
NumPy and PyTorch rules for combining arrays of different shapes by virtually stretching size-1 dimensions. 01

C

Cache breakpoint
A marker on a content block that tells the provider to cache the processed prompt up to that point. 16
Catastrophic forgetting
Losing general abilities when a model is trained hard on a narrow task. 18
Chain-of-thought
Prompting or training a model to produce intermediate reasoning before its final answer. 11
Chat template
The special-token format a chat model was trained with to mark system, user and assistant turns. Training and serving must use the same one. 18
Chunking
Splitting documents into retrievable pieces for RAG. 14
CLIP
A model that embeds images and text into a shared space, enabling zero-shot image classification and cross-modal search. 23
Cohen's kappa
Agreement between two graders corrected for chance agreement; used to calibrate an LLM judge against human labels. 17
Cold start
The problem of recommending to new users, or recommending new items, that have no interaction history yet. 28
Collaborative filtering
Recommending from the behaviour of many users: people who agreed in the past tend to agree again. 28
Compaction
Replacing a long stretch of conversation or agent transcript with a shorter summary that keeps the facts and decisions. 16
Constraint satisfaction problem
A problem defined by variables, the values each can take and constraints on which combinations are allowed, solved by an assignment that breaks no constraint. 24
Contamination
Test cases leaking into training data, prompts or few-shot examples, so that a score no longer measures generalisation. 17
Context engineering
Deciding, on every model call, what goes into the context window, in what form and in what order. 16
Context window
The maximum number of tokens (input plus output) a model can attend to in one request. 09
Context window budget
The number of input tokens you choose to spend per request, set below the window's limit and tracked per component. 16
Contrastive learning
Training that pulls matching pairs together and pushes non-matching pairs apart in an embedding space. 13
Cosine similarity
The cosine of the angle between two vectors: 1 for same direction, 0 for perpendicular. The standard similarity for embeddings. 02
Cross-encoder
A model that reads a query and a document together to score relevance. Accurate but slow; used for reranking. 14
Cross-entropy
The loss −log p(correct answer). The training objective of classifiers and LLMs. 02
Cross-validation
Training and validating k times on different splits of the data and averaging, for a more reliable estimate. 03

D

Data leakage
Information in training or evaluation data that would not be available at prediction time, producing falsely good scores. 03
Data parallelism
Training with a full copy of the model on every device, each processing different data, with gradients averaged by an all-reduce. 29
Decision log
A running record of each significant design choice: what was chosen, the alternatives, the evidence, and the result. It becomes the most convincing part of a write-up. 32
Decoder-only
A transformer with causal attention trained to predict the next token. The architecture of GPT-style LLMs. 08
Deep learning
Machine learning with many-layered neural networks that learn their own features from raw data. 00
Design document
A short written plan for a system covering the problem, data, approach, architecture, evaluation, risks, operations and iteration plan, written before the code so that assumptions can be challenged while they are still cheap to change. 31
Dice coefficient
An overlap score for masks: twice the shared area divided by the sum of the two areas, so 1 means a perfect match. 27
Diffusion model
A generative model that learns to remove noise step by step, generating images (or audio, video) from pure noise. 23
Distillation
Training a small student model to imitate a larger teacher. 18 19
Drift
A change over time in the inputs a deployed system receives or in the outputs it produces, which can degrade quality without any error. 21
Dropout
Randomly zeroing activations during training to reduce overfitting. 05

E

ELBO (evidence lower bound)
A lower bound on a model's log-likelihood, equal to a reconstruction term minus a KL term, that VAEs maximise because the likelihood itself is intractable. 26
Embedding
A learned vector representation whose geometry reflects meaning. 07 13
Episodic memory
A record of what happened in past sessions: events, requests and outcomes. 16
Epoch
One full pass over the training data. 05
Evaluation set (golden dataset)
A curated set of inputs with expected outcomes or grading criteria used to measure a system. 17
Expert system
A program that stores a specialist's knowledge as if-then rules and applies them to the facts of a case to reach conclusions. 24
Exploration vs exploitation
The trade-off between trying actions to learn more about them and choosing the action that currently looks best. 25

F

F1 score
The harmonic mean of precision and recall. 03
Few-shot prompting
Including worked examples of the task in the prompt. 11
FID (Fréchet Inception Distance)
A score for image generators that compares the mean and covariance of network features of real and generated images; lower is better. 26
Fine-tuning
Continuing to train a pretrained model on task-specific data. 18
FlashAttention
An exact attention algorithm that avoids materialising the full attention matrix in slow GPU memory, making long contexts faster. 08
FLOPs
Floating-point operations; training a transformer costs about 6 × parameters × tokens. 09
Flow matching
Training a network to predict the velocity that carries noise to data along simple paths, then generating by integrating that velocity starting from noise. 26
FSDP (ZeRO)
Data parallelism that shards optimiser state, gradients and, at stage 3, weights across devices instead of copying them to all. 29

G

GAN (generative adversarial network)
A generator and a discriminator trained against each other: the generator makes fakes and the discriminator tries to tell them from real data. 26
Generative AI
Models that produce new text, images, audio, video or code, including but not limited to LLMs. 00
Generative model
A model that learns the probability distribution of its training data, so it can score how plausible an example is, generate new examples, or both. 26
Grader
A function that turns a system output into a score: a code rule, a reference metric or an LLM judge. 17
Gradient
The vector of partial derivatives of the loss with respect to each parameter; points uphill. 02
Gradient accumulation
Summing gradients over several small micro-batches before one optimiser step, to train with a batch larger than fits in memory. 29
Gradient boosting
An ensemble of shallow trees added one at a time, each correcting the errors of the ones before. Often the best model for tabular data. 04
Gradient checkpointing
Saving only some activations in the forward pass and recomputing the rest during the backward pass, trading extra compute for less memory. 29
Gradient descent
Repeatedly stepping parameters against the gradient to reduce the loss. 02
Graph neural network
A neural network that learns on graphs by repeatedly updating each node's vector from its neighbours' vectors. 28
Grouped-query attention (GQA)
Many query heads sharing fewer key-value heads, shrinking the KV cache. 08
GRPO
Group relative policy optimisation: a PPO variant that samples several answers per prompt and uses each answer's reward relative to its group as the advantage, with no value network. 25
Guardrails
Controls around a model: input and output checks, permissions, approvals and limits. 22

H

Hallucination
Fluent, confident output that is false or unsupported. 09
Heuristic (admissible)
An estimate of the remaining cost from a state to the goal; it is admissible if it never overestimates the true cost. 24
HNSW
A graph-based approximate nearest-neighbour index, the default in many vector databases. 13
Human in the loop
A design in which a person reviews, approves or corrects a model's output before it takes effect. Used where mistakes are costly, and as a free source of evaluation data. 31
Hybrid search
Combining keyword and embedding retrieval, typically with reciprocal rank fusion. 14
Hyperparameter
A setting chosen rather than learned, such as learning rate, tree depth or LoRA rank. 03

I

Inference
Using a trained model to make predictions or generate output. 21
Instance segmentation
Giving each individual object its own pixel mask, so two touching cars get two separate masks. 27
Integrated gradients
An attribution method that averages gradients along a straight path from a baseline input to the real one, so the attributions add up to the change in output. 30
Interpretability
How well a person can understand why a model produced an output or what it has learned; explainability usually refers to the methods that produce that understanding. 30
IoU (intersection over union)
The area two regions share divided by the area they cover together: 1 for a perfect match, 0 for no overlap. 27
Isolation Forest
An anomaly detector that isolates points with random splits; anomalies isolate quickly. 04

K

KL divergence
A measure of how one probability distribution differs from another; used in distillation and RLHF. 02
KV cache
Stored keys and values of previous tokens that make generation efficient at the cost of memory. 08

L

Large language model (LLM)
A transformer trained on huge text corpora to predict the next token, then tuned to follow instructions. 00
Latency budget
The total time a request may take, split across its stages (network, retrieval, prefill, generation, tools) so that every component has a target and the slowest stage is obvious. 31
Latent space
The space of compressed codes a model works in; nearby codes usually decode to similar outputs. 26
Layer normalisation
Rescaling each token's features to zero mean and unit variance; stabilises transformer training. 05
Learning rate
The step size in gradient descent; the most important training hyperparameter. 02
LIME
Local Interpretable Model-agnostic Explanations: explaining one prediction by fitting a simple weighted model to the black box's outputs on perturbed copies of the input. 30
Linear probe
A linear classifier trained on a model's frozen internal activations to test whether some piece of information can be read from them. 30
LLM-as-judge
Using a model to grade outputs against a rubric; must be calibrated against human judgement. 17
Logit lens
Reading an intermediate layer by passing its residual stream through the model's final unembedding, as if the network stopped there. 30
Logits
Raw, unnormalised model scores before softmax. 02
LoRA
Low-rank adaptation: fine-tuning by learning a small low-rank update beside frozen weights. 18
Loss function
The number training minimises, measuring how wrong the model is. 02

M

Machine learning (ML)
Behaviour learned from data rather than programmed by hand. 00
mAP (mean average precision)
The area under the precision-recall curve, averaged over classes and, in COCO's version, over IoU thresholds from 0.5 to 0.95. 27
MASE
Mean absolute scaled error: a forecast's mean absolute error divided by that of a naive forecast on the training data, so values below 1 beat the naive method. 28
Matrix factorisation
Approximating the sparse user-item matrix by the product of small user and item vector matrices, whose dot products predict preferences. 28
Matryoshka embeddings
Embeddings trained so that their first k dimensions already form a good smaller embedding, allowing truncation with little quality loss. 13
MCP (Model Context Protocol)
An open standard for exposing tools, resources and prompts to AI applications. 15
Memory tool
A tool the model calls to read, write and update notes that persist between conversations. 16
Message passing
The core step of a graph neural network: each node gathers its neighbours' vectors, aggregates them and updates its own. 28
MFU (model FLOPs utilisation)
The fraction of the hardware's peak FLOP/s that goes into the model's own arithmetic, about 6 times parameters times tokens per second. 29
Minimax
Choosing moves in a two-player game by assuming the opponent always replies with the move that is worst for you. 24
Mixed precision
Training or inference mostly in 16-bit floating point for speed and memory, keeping sensitive parts in 32-bit. 06
Mixture of experts (MoE)
Layers with many expert sub-networks and a router that sends each token to a few of them. 09
Mode collapse
A failure in which a generative model produces only a few kinds of output and ignores the rest of the data distribution. 26
Model routing
Sending each request to the cheapest model expected to handle it well and escalating hard cases to a stronger one. 12
Monte Carlo tree search
Game-tree search that grows a tree from many simulated games, balancing moves that have done well against moves that have rarely been tried. 24
Multi-head attention
Several attention operations in parallel on smaller subspaces, then combined. 08

N

Naive Bayes
A classifier that applies Bayes' rule while assuming the features are independent of each other once the class is known. 24
NDCG
Normalised discounted cumulative gain: a ranking metric that rewards relevant items more the nearer they are to the top, scaled so a perfect ranking scores 1. 28
Non-maximum suppression (NMS)
A clean-up step that keeps the highest-scoring box, deletes the boxes that overlap it too much, and repeats with what is left. 27
Normalising flow
A generative model built from invertible transformations of simple noise, which gives exact likelihoods through the change of variables formula. 26

O

Object detection
Finding every object of interest in an image and giving each one a bounding box, a class and a confidence score. 27
Open-vocabulary detection
Detecting objects named in free text by comparing region embeddings with text embeddings, so new classes need no retraining. 27
Outcome reward model
A model trained to score only the final answer of a solution, with no view of the steps. 12
Overfitting
Learning the noise in the training data; low training error, high validation error. 03

P

PageRank
A node importance score: the long-run share of time a random walker that follows edges, with occasional random jumps, spends at each node. 28
Paired comparison
Comparing two systems case by case on the same inputs, which is far more sensitive than comparing two averages. 17
Partial dependence plot
A curve of the model's average prediction as one feature is set to each value in turn for every row; ICE curves show the same sweep for individual rows. 30
pass@k
The probability that at least one of k independent attempts solves a problem; pass^k is the probability that all k do. 12
PCA
Projecting data onto its directions of greatest variance, for compression or visualisation. 04
Permutation importance
How much a model's held-out score drops when one feature's values are shuffled, which breaks that feature's link with the target. 30
Pipeline parallelism
Placing consecutive blocks of layers on different devices and streaming micro-batches through them like an assembly line. 29
Policy
The rule an agent uses to choose an action in each state, often a probability distribution over actions. 25
Policy gradient
A family of methods that adjust a policy's parameters directly, raising the probability of actions that led to higher-than-expected return. 25
Positional encoding
Information about token order added to a transformer, which is otherwise order-blind (learned, sinusoidal or RoPE). 08
PPO
Proximal policy optimisation: a policy-gradient method that clips the probability ratio between the new and old policy so each update stays small. 25
Precision and recall
Precision: of the positives predicted, the fraction that were right. Recall: of the real positives, the fraction found. 03
Prefill
Processing the prompt before generating the first token; also, starting the assistant's reply with given text. 11 20 21
Pretraining
Training a model on a huge unlabelled corpus with next-token prediction. 09
Process reward model
A model trained to score each intermediate step of a solution, which makes step-level search possible. 12
Prompt caching
Reusing the processed form of a repeated prompt prefix at reduced cost and latency. 10
Prompt chaining
Splitting a job into several focused model calls that pass their outputs forward. 11
Prompt injection
Text that tries to override a system's instructions, directly from a user or indirectly via content the model reads. 22
Prompt optimisation
Searching automatically over instructions and examples, scored on a labelled set, instead of editing a prompt by hand. 11

Q

Q-function
The expected return from taking a given action in a given state and following the policy afterwards. 25
Q-learning
An off-policy algorithm that learns the optimal Q-function by moving each estimate towards the reward plus the discounted best next value. 25
QLoRA
LoRA on top of a base model stored in 4-bit precision. 18
Quantisation
Storing weights (or activations, or the KV cache) in fewer bits to save memory and speed up inference. 20 21

R

RAG (retrieval-augmented generation)
Retrieving relevant documents at question time and asking the model to answer from them. 14
Rate limit
A provider's cap on requests or tokens per minute for an account; exceeding it returns HTTP 429. 10
Reasoning faithfulness
Whether a model's visible reasoning reflects the computation that actually produced its answer. 12
Reasoning model
A model trained to produce extended reasoning before answering, improving with more test-time compute. 09
Reciprocal rank fusion (RRF)
Merging rankings by summing 1/(k + rank) across retrievers. 14
Regularisation
Techniques that discourage overly complex models, such as weight penalties, dropout and early stopping. 03
Reparameterisation trick
Writing a random sample as a deterministic function of the parameters plus independent noise, such as z = μ + σε, so that gradients can flow through the sampling step. 26
Reranker
A model, usually a cross-encoder, that reorders retrieved candidates by relevance. 14
Residual connection
Adding a layer's input to its output (x + f(x)), letting gradients flow through deep networks. 05
Return
The total, usually discounted, reward collected from a point in time to the end of an episode; what an RL agent tries to maximise. 25
Reward
The number an environment returns after each action, saying how good that step was. 25
Reward hacking
When an agent maximises the reward signal in a way its designers did not intend, exploiting flaws in the reward instead of doing the task. 25
RLHF
Reinforcement learning from human feedback: optimising a model against a reward model trained on human preferences. 09
Rolling summary
A summary of earlier turns that is updated each time old turns are folded into it. 16
Roofline model
A performance model in which achievable speed is the lower of peak compute and arithmetic intensity times memory bandwidth. 29
RoPE
Rotary position embeddings, which encode relative position by rotating queries and keys. 08
Rubric
A table of the dimensions on which work is judged, with a description of what developing, solid and excellent look like on each, so that assessment is consistent and the target is visible before you start. 32

S

Saliency map
A map of how sensitive a network's output is to each input pixel, usually the absolute value of the gradient. 30
Scaling laws
Empirical power laws relating model loss to parameters, data and compute. 09
Seasonality
A pattern that repeats with a fixed period, such as a daily, weekly or yearly cycle. 28
Self-consistency
Sampling several reasoning chains for the same question and returning the most common final answer. 12
Self-supervised learning
Learning from labels derived from the data itself, such as the next word. 03
Semantic cache
A response cache that matches new questions to stored ones by embedding similarity rather than exact text. 21
Semantic memory
Stored facts about the user or the world, independent of when they were learned. 16
Semantic segmentation
Assigning a class to every pixel of an image, without separating different objects of the same class. 27
SFT (supervised fine-tuning)
Fine-tuning on examples of desired inputs and outputs. 09 18
Shadow deployment
Running a candidate system on live traffic in parallel without showing its outputs, to compare it with the current one. 21
Shapley value (SHAP)
A feature's average marginal contribution to one prediction over all orders in which features could be added; the contributions sum to the prediction minus a baseline. 30
Softmax
Converts logits to probabilities that sum to 1. 02
Sparse autoencoder
A wide autoencoder trained to rebuild activations from a few active features at a time, used to split superposed representations into interpretable directions. 30
State-space model
A sequence model that carries a fixed-size state forward with a linear recurrence, so its cost grows linearly with sequence length. 29
Stationarity
The property of a series whose mean, variance and autocorrelation do not change over time; most classical forecasting models assume it. 28
Stop reason
The field in a response that says why generation ended: the model finished, hit the token cap, wants to call a tool, or refused. 10
Streaming
Sending generated tokens to the client as they are produced. 10
STRIPS
A planning representation in which a state is a set of true facts and each action has preconditions, facts it adds and facts it deletes. 24
Structured output
Constraining model output to a schema, then validating it. 10
Sub-agent
A separate model loop with its own context window that does a sub-task and returns a short result to the parent. 16
Superposition
A network representing more features than it has dimensions, by giving sparse features directions that are almost, but not exactly, orthogonal. 30
Symbolic AI
AI built from explicit symbols, rules and search procedures written by people, rather than from patterns learned from data. 24
System prompt
Standing instructions and context for a conversation. 10

T

Temperature
Divides logits before softmax; low values make output more deterministic, high values more random. 09
Tensor
A multi-dimensional array, the core data structure of deep learning frameworks. 06
Tensor parallelism
Splitting each layer's weight matrices across devices so that they compute every layer together. 29
Test-time compute
Spending more computation at inference (longer reasoning, sampling several answers) to improve accuracy. 09
Thinking budget
A cap on how many tokens a reasoning model may spend thinking before it answers; current APIs often expose it as an effort level instead. 12
Time series
A sequence of measurements ordered in time, where each value usually depends on the ones before it. 28
Token
The unit of text a model reads and writes, typically a word piece of about four characters in English. 09
Tool use (function calling)
A model requesting structured calls to functions your code executes. 15
Top-p (nucleus) sampling
Sampling only from the smallest set of tokens whose probabilities sum to p. 09
Tracing
Recording every step of a request (retrieval, model calls, tools) for debugging and monitoring. 21
Transfer learning
Reusing a model trained on one task as the starting point for another. 06
Transformer
The architecture of stacked attention and MLP blocks with residual connections and normalisation behind modern LLMs. 08
TTFT (time to first token)
Latency until the first output token appears; dominated by prompt length. 20 21
Two-tower model
A retrieval model with separate networks that embed users and items in one vector space, so candidates can be found by nearest-neighbour search. 28

U

U-Net
An encoder-decoder segmentation network whose skip connections pass detailed encoder features straight to the decoder at each resolution. 27
Underfitting
A model too simple to capture the pattern; high training and validation error. 03
Uniform-cost search
Search that always expands the cheapest path found so far, so it finds the lowest-cost route when no step cost is negative; Dijkstra's algorithm stopped at the goal. 24

V

VAE (variational autoencoder)
An autoencoder trained as a probabilistic model, with its codes pulled towards a simple prior so that decoding random codes produces new data. 26
Value function
The expected return from a state when following a given policy. 25
Vector database
A database that stores embeddings with metadata and supports similarity search with filters. 13
Verifier
A program or model that checks whether a candidate answer is correct, from unit tests to a learned reward model. 12
Virtual environment
An isolated Python installation per project, so each project pins its own library versions. 00
Vision transformer (ViT)
A transformer that processes images as sequences of patches. 23
VLM (vision-language model)
A model that accepts images alongside text. 23

W

Walking skeleton
The crudest version of a system that runs end to end through every stage, built first so that integration problems and measurement exist from day one. Each stage is then improved in turn. 32
Weight decay
An L2-style penalty that shrinks weights during training. 03

Z

Zero-shot
Performing a task with no task-specific examples or training. 23
