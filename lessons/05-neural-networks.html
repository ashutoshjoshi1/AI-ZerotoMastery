Why build one by hand?#

You will never ship a hand-written neural network; PyTorch does this better. But writing one once, including backpropagation, removes the mystery for good. When a large model's loss turns to nan, when gradients vanish, or when someone says "the residual stream" or "layer norm", you will know what is physically happening to the numbers. That understanding is what separates engineers who can debug models from those who can only call them.

The neuron#

An artificial neuron computes a weighted sum of its inputs plus a bias, then applies a non-linear activation function:

a=ϕ(w⋅x+b)a = \phi(\mathbf{w}\cdot\mathbf{x} + b)a=ϕ(w⋅x+b)

That is logistic regression from lesson 04 when ϕ\phiϕ is the sigmoid. A layer is many neurons side by side, each with its own weights, so it is one matrix multiplication: for a batch XXX of shape (batch, n_in) and weights WWW of shape (n_in, n_out), the layer outputs ϕ(XW+b)\phi(XW + \mathbf{b})ϕ(XW+b) of shape (batch, n_out).

Why non-linearity is essential#

Stack two linear layers without an activation: (XW1)W2=X(W1W2)(XW_1)W_2 = X(W_1W_2)(XW1​)W2​=X(W1​W2​), which is just one linear layer. Depth buys nothing. The activation function is what lets each layer bend the space, so a stack can represent curved decision boundaries and, in principle, any continuous function (the universal approximation theorem).

The classic demonstration is XOR: output 1 when exactly one input is 1. No straight line separates the two classes, so no linear model can learn it, but one hidden layer can.

Activation functions#

Function Formula Notes
Sigmoid 1/(1+e−z)1/(1+e^{-z})1/(1+e−z) Squashes to (0, 1). Used for binary outputs. Saturates, so gradients vanish in deep stacks.
Tanh tanh⁡(z)\tanh(z)tanh(z) Squashes to (−1, 1), zero-centred. Also saturates.
ReLU max⁡(0,z)\max(0, z)max(0,z) The workhorse since 2012. Cheap, does not saturate for positive inputs. Neurons can "die" if always negative.
GELU / SiLU smooth ReLU variants Used inside transformers. Slightly better behaved around zero.
Softmax ezi/∑jezje^{z_i}/\sum_j e^{z_j}ezi​/∑j​ezj​ Output layer for multi-class problems (lesson 02).

The forward pass#

We will classify the "two moons" dataset: two interlocking crescents that no straight line can separate. The network has two hidden layers of 16 ReLU neurons and a sigmoid output.

Python
import numpy as np
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=1000, noise=0.2, random_state=0)
y = y.reshape(-1, 1).astype(float)          # (1000, 1) so shapes line up with the output
rng = np.random.default_rng(0)

def relu(z):    return np.maximum(0, z)
def sigmoid(z): return 1 / (1 + np.exp(-z))

def init(sizes):
    """He initialisation: weights ~ N(0, 2/n_in), good for ReLU."""
    params = {}
    for i, (n_in, n_out) in enumerate(zip(sizes[:-1], sizes[1:]), start=1):
        params[f"W{i}"] = rng.normal(0, np.sqrt(2 / n_in), (n_in, n_out))
        params[f"b{i}"] = np.zeros(n_out)
    return params

def forward(params, X):
    z1 = X @ params["W1"] + params["b1"];  a1 = relu(z1)        # (B, 16)
    z2 = a1 @ params["W2"] + params["b2"]; a2 = relu(z2)        # (B, 16)
    z3 = a2 @ params["W3"] + params["b3"]; p = sigmoid(z3)      # (B, 1)
    cache = (X, z1, a1, z2, a2, p)                              # saved for the backward pass
    return p, cache

def bce(p, y, eps=1e-9):
    return -np.mean(y * np.log(p + eps) + (1 - y) * np.log(1 - p + eps))

params = init([2, 16, 16, 1])
p, _ = forward(params, X)
print(p.shape, bce(p, y))                   # (1000, 1) about 0.7: random guessing

A loss around ln⁡2≈0.69\ln 2 \approx 0.69ln2≈0.69 is what you get from predicting 0.5 for everything. That is a useful sanity check: an untrained binary classifier should start near 0.69, and an untrained 10-class classifier near ln⁡10≈2.3\ln 10 \approx 2.3ln10≈2.3. If yours starts far from that, something is wrong before training even begins.

Backpropagation#

We need ∂L/∂W\partial L/\partial W∂L/∂W for every weight. Backpropagation computes them all in one backward sweep, applying the chain rule layer by layer from the loss to the inputs and reusing intermediate results so nothing is computed twice.

Deriving it, one layer at a time#

Work backwards. For sigmoid output with binary cross-entropy, the gradient with respect to the pre-activation z3z_3z3​ simplifies beautifully (the same simplification you saw in logistic regression):

∂L∂z3=1B(p−y)\frac{\partial L}{\partial z_3} = \frac{1}{B}(p - y)∂z3​∂L​=B1​(p−y)

For any linear layer z=aW+bz = aW + bz=aW+b, given the upstream gradient δ=∂L/∂z\delta = \partial L/\partial zδ=∂L/∂z:

∂L∂W=a⊤δ,∂L∂b=∑batchδ,∂L∂a=δ W⊤\frac{\partial L}{\partial W} = a^\top \delta, \qquad \frac{\partial L}{\partial b} = \textstyle\sum_{\text{batch}} \delta, \qquad \frac{\partial L}{\partial a} = \delta\, W^\top∂W∂L​=a⊤δ,∂b∂L​=∑batch​δ,∂a∂L​=δW⊤

And through a ReLU, the gradient passes unchanged where the input was positive and is blocked where it was negative:

∂L∂z=∂L∂a⊙1[z>0]\frac{\partial L}{\partial z} = \frac{\partial L}{\partial a} \odot \mathbb{1}[z > 0]∂z∂L​=∂a∂L​⊙1[z>0]

Check the shapes, which is how you remember these: a⊤a^\topa⊤ is (16, B) and δ\deltaδ is (B, 1), so a⊤δa^\top\deltaa⊤δ is (16, 1), the shape of W3W_3W3​. The gradient of every parameter always has the same shape as the parameter.

Python
def backward(params, cache, y):
    X, z1, a1, z2, a2, p = cache
    B = len(y)
    dz3 = (p - y) / B                           # (B, 1)
    grads = {"W3": a2.T @ dz3, "b3": dz3.sum(0)}
    da2 = dz3 @ params["W3"].T                  # (B, 16)
    dz2 = da2 * (z2 > 0)                        # through ReLU
    grads["W2"] = a1.T @ dz2
    grads["b2"] = dz2.sum(0)
    da1 = dz2 @ params["W2"].T                  # (B, 16)
    dz1 = da1 * (z1 > 0)
    grads["W1"] = X.T @ dz1
    grads["b1"] = dz1.sum(0)
    return grads

Trust, but verify#

Never trust a hand-written backward pass until it passes a gradient check (lesson 02).

Python
params = init([2, 16, 16, 1])
p, cache = forward(params, X[:20])
g = backward(params, cache, y[:20])

eps = 1e-5
for k in ["W1", "b2", "W3"]:
    idx = (0, 0) if params[k].ndim == 2 else (0,)
    old = params[k][idx]
    params[k][idx] = old + eps; lp = bce(forward(params, X[:20])[0], y[:20])
    params[k][idx] = old - eps; lm = bce(forward(params, X[:20])[0], y[:20])
    params[k][idx] = old
    print(k, g[k][idx], (lp - lm) / (2 * eps))   # the two columns should agree to ~8 digits

This is exactly what PyTorch's autograd does for you automatically, for any composition of operations: it records the forward pass as a graph and walks it backwards applying these rules. Lesson 06 hands this job over to the machine.

Training it#

Mini-batches#

Computing the gradient on all 800 training examples per step is slow; using one example is noisy. Mini-batch gradient descent uses a batch of, say, 32. The noise is actually helpful: it jolts the model out of poor regions. One pass over the training data is an epoch.

Optimisers: momentum and Adam#

Plain SGD steps straight down the current gradient, which zig-zags in narrow valleys. Momentum keeps a running average of past gradients, like a ball rolling downhill, smoothing the zig-zags. Adam adds a per-parameter step size: parameters with consistently large gradients get smaller steps, rarely-updated ones get larger steps. Adam (and its variant AdamW, with decoupled weight decay) is the default for training transformers.

m←β1m+(1−β1)g,v←β2v+(1−β2)g2,θ←θ−η m^v^+ϵm \leftarrow \beta_1 m + (1-\beta_1) g, \quad v \leftarrow \beta_2 v + (1-\beta_2) g^2, \quad \theta \leftarrow \theta - \eta\,\frac{\hat m}{\sqrt{\hat v} + \epsilon}m←β1​m+(1−β1​)g,v←β2​v+(1−β2​)g2,θ←θ−ηv^​+ϵm^​

where m^\hat mm^ and v^\hat vv^ are bias-corrected versions that fix the cold start at zero.

Python
class Adam:
    def __init__(self, params, lr=1e-2, b1=0.9, b2=0.999, eps=1e-8):
        self.lr, self.b1, self.b2, self.eps, self.t = lr, b1, b2, eps, 0
        self.m = {k: np.zeros_like(v) for k, v in params.items()}
        self.v = {k: np.zeros_like(v) for k, v in params.items()}

    def step(self, params, grads):
        self.t += 1
        for k in params:
            self.m[k] = self.b1 * self.m[k] + (1 - self.b1) * grads[k]
            self.v[k] = self.b2 * self.v[k] + (1 - self.b2) * grads[k] ** 2
            m_hat = self.m[k] / (1 - self.b1 ** self.t)
            v_hat = self.v[k] / (1 - self.b2 ** self.t)
            params[k] -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

The training loop#

Python
idx = rng.permutation(len(X))
tr, va = idx[:800], idx[800:]

params = init([2, 16, 16, 1])
opt = Adam(params, lr=0.01)
for epoch in range(200):
    perm = rng.permutation(tr)                       # reshuffle every epoch
    for start in range(0, len(perm), 32):
        b = perm[start:start + 32]
        p, cache = forward(params, X[b])             # 1. forward
        grads = backward(params, cache, y[b])        # 2. backward
        opt.step(params, grads)                      # 3. update
    if epoch % 50 == 0:
        p_va, _ = forward(params, X[va])
        print(epoch, round(((p_va > 0.5) == y[va]).mean(), 3))
# validation accuracy reaches about 0.96 to 0.97; logistic regression manages about 0.89

You have trained a neural network with nothing but NumPy. Every deep learning framework is, at heart, this loop with automatic gradients, GPU kernels and a library of layers.

Making deep networks train#

Three layers train easily. Fifty do not, without help. These are the techniques that made depth practical, and every one appears inside a transformer.

Initialisation. If weights start too large, activations explode layer after layer; too small, and they shrink to nothing. He initialisation (N(0,2/nin)\mathcal{N}(0, 2/n_{\text{in}})N(0,2/nin​) for ReLU) and Xavier/Glorot initialisation (for tanh) keep the signal's variance roughly constant through the layers.

Vanishing and exploding gradients. Backprop multiplies many factors together. If they are mostly below 1, gradients vanish and early layers stop learning; above 1, they explode. Fixes: ReLU-family activations, good initialisation, normalisation layers, residual connections and gradient clipping (cap the gradient norm before each step).

Residual connections. Instead of a=f(x)a = f(x)a=f(x), compute a=x+f(x)a = x + f(x)a=x+f(x). The identity path gives gradients a highway straight back to early layers, which is why ResNets reached 150 layers in 2015 and why every transformer block wraps its sub-layers this way.

Normalisation. Batch normalisation rescales each feature to zero mean and unit variance across the batch; layer normalisation does it across features within each example, which works for any batch size and for sequences. Transformers use layer norm (or its cheaper cousin RMSNorm).

Dropout. During training, randomly zero a fraction of activations (say 10%), scaling the rest up to compensate. The network cannot rely on any single neuron, which reduces overfitting. At inference time, dropout is switched off.

Learning-rate schedules. Start with a short warm-up (ramp the learning rate up from near zero) so Adam's statistics settle, then decay it (cosine decay is common) so the model can settle into a minimum. Nearly every LLM is trained this way.

Early stopping. Watch validation loss; when it stops improving for a few epochs, stop and keep the best checkpoint.

Hands-on: experiments that build intuition

At your computer 05-neural-networks.ipynb, cell “Hands-on: experiments that build intuition”

Using the NumPy network above, run each experiment and write one sentence in your log about what you saw.

  1. Remove both ReLUs (make them identity functions). What happens to validation accuracy, and why?
  2. Replace He initialisation with rng.normal(0, 1.0, ...) and with rng.normal(0, 0.01, ...). Print the loss in the first few epochs.
  3. Replace Adam with plain SGD at learning rates 0.01, 0.1 and 1.0.
  4. Stretch: add dropout to the hidden layers in training (multiply by a random mask, divide by the keep probability) and check whether the gap between training and validation accuracy shrinks with noise=0.35.
Show what you should find
  1. No activations: accuracy falls to about 0.89, the same as logistic regression. Without non-linearity the whole network collapses into one linear layer, so it can only draw a straight boundary.
  2. Initialisation: with standard deviation 1.0, initial activations and the loss are large and training is erratic at first (it may recover on such a small network). With 0.01, the signal nearly vanishes through the layers and the loss sits near 0.69 for a while before learning starts. Deeper networks would fail outright.
  3. SGD: 0.01 learns slowly, 0.1 works well (about 0.96), and 1.0 may oscillate or diverge. Adam is far less sensitive to the exact learning rate, which is a big reason for its popularity.
  4. Dropout in the backward pass must apply the same mask to the gradient:
    Python
    keep = 0.9
mask1 = (rng.random(a1.shape) < keep) / keep
a1 = a1 * mask1             # forward, training only
# backward: da1 = da1 * mask1 before multiplying by the ReLU mask
    On noisier data the train/validation gap usually narrows a little. On a problem this small the effect is modest; on large networks it matters much more.

Check yourself#

1. What happens if you stack ten linear layers with no activation functions?

Matrix products compose into one matrix. Non-linear activations are what give depth its power.

2. In backprop, what shape is the gradient of a weight matrix W of shape (64, 32)?

A parameter's gradient always has the same shape as the parameter, which is a handy check when deriving them.

3. An untrained 10-class classifier starts with a loss of 45. What does that suggest?

A sensible untrained model predicts roughly uniform probabilities. Far higher means confident wrong outputs, usually from bad initialisation or a bug.

4. What do residual connections (a = x + f(x)) mainly help with?

The identity path is a gradient highway. Every transformer block uses residual connections.

5. Why is dropout switched off at inference time?

During training the activations are rescaled so the expected output matches the inference-time network.

Key takeaways

  • A layer is activation(X @ W + b). Non-linear activations are what make depth useful.
  • Backpropagation is the chain rule applied from the loss backwards: for a linear layer, dW = aᵀ·δ, da = δ·Wᵀ; ReLU passes gradient only where its input was positive.
  • Verify hand-written gradients with a gradient check. Sanity-check the initial loss (about ln of the number of classes).
  • Training is forward, backward, update, over shuffled mini-batches. Adam is the robust default optimiser.
  • Initialisation, residual connections, normalisation, dropout, gradient clipping and learning-rate schedules are what make deep networks, including transformers, trainable.
