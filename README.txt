AI Engineering: from zero to mastery
=====================================

Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).
Everything works offline: fonts, maths and code highlighting are bundled.

Layout
  index.html        course home, the route, progress
  schedule.html     the whole course as one-hour daily sessions
  lessons/          22 lessons, 00 to 21
  notebooks/        a Jupyter notebook per lesson, plus worked solutions;
                    see notebooks/README.md for running them locally or on Colab
  glossary.html     terms you will meet, in plain language
  resources.html    books, courses, papers and tools for going deeper
  assets/           styles, scripts, fonts

Progress ticks are saved in your browser's local storage for this folder.
Keyboard: press / to search.
